# Restringir-Permisos-CMD-Powershell-Scripting
He creado este script Powershell para restringir los permisos de CMD, Powershell, bitsadmin y wscript a todos los usuarios que no sean admin o administrador. Recomiendo ejecutar este script para evitar que autores malintencionados usen las herramientas nativas de Windows de ejecución de comandos para realizar actividades maliciosas no deseadas.
